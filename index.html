Cyber-Physical Motion Control

Smartphone Motion → Pan-Tilt Platform

A phone's orientation (roll / pitch / yaw), streamed live over Wi-Fi from Phyphox, drives a 2-DOF pan-tilt servo gimbal in real time — filtered, rate-limited, and now controllable from a self-hosted web dashboard with no home router required.

System Architecture

มือถือเป็นเซนเซอร์ทิศทาง — ESP32-S3 เป็นทั้งตัวควบคุมและ Wi-Fi Access Point ของตัวเอง

ทั้งหมดอยู่ในวง Wi-Fi เดียวกันที่ ESP32-S3 ปล่อยเอง — ไม่ต้องมีอินเทอร์เน็ต ไม่ต้องพึ่งเราเตอร์บ้าน

Progress Timeline

ลำดับที่ทำมาจริงจาก commit history ของ repo

Phase 1
Real-time 3-D RPY visualizer (Python + Phyphox)

อ่านค่า attitude จากมือถือผ่าน Phyphox แสดงโมเดลโทรศัพท์ 3 มิติด้วย VPython พร้อม Kalman filter และ FFT วิเคราะห์ความถี่การสั่น

Phase 2
ESP32 firmware — phone hotspot (STA) + low-pass filter

ESP32 ต่อ Wi-Fi ของมือถือเป็น client แล้ว poll ค่า pitch/yaw มาขับ servo pan-tilt ผ่าน low-pass filter → deadband → rate limiter

Phase 3
Kalman filter variant

เพิ่มตัวกรองแบบ Kalman (estimate ทั้งมุมและอัตราการเปลี่ยนแปลง) เป็นทางเลือกแทน low-pass filter สำหรับสัญญาณที่ noise เยอะ

Phase 4
ESP32-S3 กลายเป็น Access Point + Web Dashboard

เปลี่ยนจาก STA เป็น AP ปล่อย Wi-Fi เอง ไม่ต้องพึ่งเราเตอร์บ้าน พร้อมหน้าเว็บ dashboard แสดงค่า raw RPY สด และจอยสติ๊กควบคุมมือได้โดยตรง (auto / manual mode)

Phase 5 — Current
Build system + mechanical tuning

ปรับ PlatformIO ให้สลับ firmware variant (LPF / Kalman / AP Dashboard) ได้ด้วย environment เดียว ไม่ต้อง copy ไฟล์ และ tune ขอบเขตมุม pan/tilt, deadband, rate limit ให้ไม่ชนกลไกจริง
