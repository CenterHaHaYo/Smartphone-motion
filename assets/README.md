# Assets folder

Drop real photos/clips here using these exact filenames and they'll appear
on the GitHub Pages project page automatically (index.html already
references these paths) — no HTML editing needed:

## assets/img/
- hero.jpg          -> big photo at the top of the page (recommended ~1600x900)
- hardware-1.jpg     -> photo of the pan-tilt rig
- hardware-2.jpg     -> another angle / close-up (servos, wiring, mount)
- hardware-3.jpg     -> another angle (optional)

## assets/video/
- demo.mp4           -> short demo clip (phone tilt -> platform follows)
  (keep it small, a few MB — GitHub has a 100MB per-file hard limit)

If a file isn't there yet, the page just shows a placeholder box instead of
a broken image, so it's safe to push before you have media ready.
